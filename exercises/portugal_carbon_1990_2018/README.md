# Exercise 1 · Carbon storage change in mainland Portugal, 1990–2018

From land-cover snapshots to a carbon indicator, and what a satellite time series shows that the snapshots cannot.

This exercise grew out of the hands-on session *Carbon & Climate Regulation* at the ESP Summer School 2026 in Barcelona (Pedro Cabral, Felipe S. Campos, João David). It follows the same workflow and deliverables, and extends them so that every step connects to a section of the book.

| Notebook | Question it answers | Main book chapters |
|---|---|---|
| [01_data_preparation](01_data_preparation.ipynb) | Are the land-cover observations fit to be turned into an indicator? | 1, 2, 3, 4 |
| [02_invest_carbon_change](02_invest_carbon_change.ipynb) | How much did carbon storage change, why, and how confident can we be? | 3, 4, 5, 6, 8 |
| [03_satellite_vegetation_dynamics](03_satellite_vegetation_dynamics.ipynb) | What does a 25-year satellite record reveal that the carbon map cannot? | 3, 4, 5, SDG 15.3.1 |

Run them in order. Notebooks 01 and 02 work offline with the data in this folder; Notebook 03 downloads MODIS NDVI from the Microsoft Planetary Computer on its first run (no account needed) and caches it.

## Setup

From the repository root:

```bash
conda env create -f environment.yml
conda activate es-rs-book
jupyter lab exercises/portugal_carbon_1990_2018
```

`natcap.invest` 3.15 or later is required (the carbon model's arguments were renamed in 3.15). Installing through conda-forge, as above, avoids having to compile GDAL.

## Data

| File | Content | Source and licence |
|---|---|---|
| `data/clc1990_portugal.tif`, `data/clc2018_portugal.tif` | CORINE Land Cover 1990 and 2018, 100 m, EPSG:3035, clipped to mainland Portugal on the native grid | © European Union, Copernicus Land Monitoring Service, EEA. Free and open access with attribution |
| `data/portugal_mainland.gpkg`, `data/municipalities.gpkg` | Mainland outline and municipalities | Derived from CAOP, Direção-Geral do Território |
| `data/carbon_pools.csv` | Carbon density (t C ha⁻¹) by CLC grid code for four pools, used in the Barcelona tutorial | Teaching parameterization by the authors |
| `data/clip_report.json` | Checksums of the source rasters and per-class pixel counts | Generated by `scripts/clip_clc.py` |

To rebuild the clipped data from the full-Europe rasters:

```bash
python scripts/clip_clc.py \
    --clc1990 U2000_CLC1990_V2020_20u1.tif \
    --clc2018 U2018_CLC2018_V2020_20u1.tif \
    --boundary Portugal.shp \
    --caop Continente_CAOP2025.gpkg
```

**About the carbon table.** The values are a teaching parameterization, not an inventory. Two of them are deliberately left as they are because they make good discussion material: *Burnt areas* carry almost no soil carbon (Notebooks 02 and 03 examine what follows from that), and *Transitional woodland-shrub* stores more total carbon than *Coniferous forest* because of its higher soil value, so shrubland afforested with conifers registers as a loss.
